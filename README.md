# News summary — 11 November 2026

Entry for make.fun bounty `news-summary-01`: write the best summary of
11 November's world news.

`main.py` (Python 3.13, standard library only) writes one summary, in
English, of the world's news of Wednesday 11 November 2026 to
`<output>/entry.txt`. It runs with no network and writes byte-identical
output on every run.

Run it locally:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
cat out/entry.txt
```

The summary covers the day's most consequential stories — the Abu Dhabi
talks between Ukraine and Russia, the COP31 leaders' summit in Antalya,
Iran, Gaza, US politics, a Russian-espionage arrest in Britain, Spain's
general strike, markets, and Kenya's Ebola countdown — each with a named
source, in the entrant's own words.
